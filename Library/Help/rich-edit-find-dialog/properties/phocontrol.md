# phoControl - [oRichEditFind](../class.md)

[Methods](../methods.md) - [Properties](../properties.md) - [Events](../events.md)

### Type

Handle

### Default

0

### Description

The handle of the RichEdit control that invoked the dialog. Set by [DoSearch](../methods/do-search.md) and used by the Find button to address the control. Not available in the designer (`DesignTime = False`).
