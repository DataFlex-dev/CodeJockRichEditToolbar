# psDescription - [cCJRTFMenuItem](../class.md)

[Methods](../methods.md) - [Properties](../properties.md) - [Events](../events.md)

### Type

String

### Default

None

### Description

Sets the description (status bar help) of the item.

The `Set` is augmented: after forwarding the value, `psToolTip` is set to the same text, so the description and the tooltip always show the same text. Only the `Set` is augmented.

### DataFlex Framework usage

- Windows
