# EnumTypeFaces - [cTypeFaces](../class.md)

[Methods](../methods.md) - [Properties](../properties.md) - [Events](../events.md)

### Method Type

Procedure

### Arguments

None

### Description

Empties [pTypeFaces](../properties/ptype-faces.md) and starts the font enumeration (`Enumerate_Fonts ''`). After the call, [pTypeFaces](../properties/ptype-faces.md) holds one element for each typeface reported by the system.
