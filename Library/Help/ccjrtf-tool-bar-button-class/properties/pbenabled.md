# pbEnabled - [cCJRTFToolBarButton](../class.md)

[Methods](../methods.md) - [Properties](../properties.md) - [Events](../events.md)

### Type

Boolean

### Default

Inherited from `cCJMenuItem`

### Arguments

| Argument    | Type    | Description            |
|-------------|---------|------------------------|
| `bChangeTo` | Boolean | The new enabled state. |

### Description

The `Set` is augmented: the new value is forwarded only when it differs from the current value. Redundant changes are not forwarded.
